# VastNext 👋

Building practical software with **AI-assisted engineering, coding agents, and modern product development**.

VastNext is an independent software engineering lab focused on exploring how experienced software engineering practices can be combined with modern AI-assisted development.

The projects here span **AI applications, developer tools, SaaS products, browser extensions, multi-agent coding workflows, and lightweight desktop software**.

## Featured Projects

### FindryAI
AI product discovery and SaaS platform.

**Stack:** Next.js · React · TypeScript · AI APIs · Auth · Payments · CMS

A production-oriented product covering the full lifecycle from product design and architecture to implementation, deployment, SEO, content management, and operation.

### LexiLayer Translator
AI-assisted contextual translation browser extension.

**Stack:** TypeScript · Browser Extension · OpenAI-compatible APIs · Streaming · Playwright

Explores practical AI integration in the browser, including configurable domain prompts, streaming responses, dynamic-page processing, caching, and automated testing.

### OpenCode Rapid Agent Team
Heterogeneous coding-agent team for AI-assisted software delivery.

**Stack:** Python · OpenCode · Multi-Agent Systems · Coding Agents · Automation

Explores task decomposition, specialized agents, parallel software development, verification, and agent-driven engineering workflows.

### GlanceMD / GlanceMD Ultra
Lightweight native Markdown applications.

**Stack:** Rust · WebView · Desktop Application Development

Explores lightweight desktop software architecture and cross-platform development.

VastNext projects are built on more than **15 years of professional software engineering experience** across:

- Distributed systems and microservices
- Spring / Spring Boot

- Cloud-native modernization
- CI/CD and deployment automation
- Performance engineering and JVM troubleshooting
- Technical leadership and engineering team management

The current focus is combining those engineering fundamentals with **AI-assisted development and coding-agent workflows**.
